Inside the vision system

How SYMBIOSIS reads a banana leaf.

The loaded Ultralytics YOLO classification model compares visual patterns in an uploaded leaf image and returns the most likely class with a confidence score. SYMBIOSIS then joins that result with selected coordinates and current weather context to support field decisions.

AI
ACTIVE WEIGHTSmodels/best.ptLoaded locally by the Flask inference service
01

Image input

A banana leaf photo enters from single upload or batch capture. Clear, close imagery gives the model stronger visual evidence.

02

Feature analysis

YOLO processes color, texture, shape, and lesion-like patterns learned from labeled training images. It does not inspect plant tissue directly.

03

Class prediction

The model ranks four possible labels and returns the top prediction. Confidence measures model certainty, not disease severity or guaranteed accuracy.

04

Field enrichment

Coordinates place the observation on the map. Weather data adds environmental risk context; it does not change the image model prediction.

Important boundary

SYMBIOSIS supports field monitoring and early warning. It does not replace an agronomist’s diagnosis. Detection confidence and severity are model estimates — verify serious or spreading cases on the ground before treatment decisions.
